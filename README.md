## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/VarnikChoudhary/Portfolio.git
   cd Portfolio

````

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run locally**

   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173` to view your portfolio locally.
