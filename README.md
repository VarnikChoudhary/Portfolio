


# ⚡ Portfolio - Varnik Choudhary

Welcome to my personal portfolio repository! This project is a responsive, single-page application built with **React** and **Vite** to showcase my skills, professional experience, and projects.

## 🚀 Tech Stack

- **Framework:** React
- **Build Tool:** Vite
- **Styling:** CSS / Modern UI
- **Language:** JavaScript (ES6+)
- **Linting:** ESLint

## 📂 Project Structure

```
The project is organized into modular components as seen in the source code:

```text
src/
├── assets/
│   └── projects/         # Project screenshots/images
├── Components/
│   ├── Navbar.jsx        # Navigation bar
│   ├── Hero.jsx          # Landing section
│   ├── About.jsx         # Bio and introduction
│   ├── Technologies.jsx  # Skills display
│   ├── Experience.jsx    # Work history
│   ├── Education.jsx     # Academic background
│   ├── Projects.jsx      # Project showcase
│   └── Contact.jsx       # Contact form
├── constants/            # Static data and configs
├── App.jsx               # Main layout
└── main.jsx              # Entry point

```

## ✨ Features

* **Hero Section:** Engaging introduction.
* **Dynamic Content:** Components for Experience, Education, and Projects.
* **Responsive Design:** Optimized for all device sizes.
* **Contact Integration:** Ready-to-use contact form structure.

## 🛠️ Installation & Setup

1. **Clone the repository:**
```bash
git clone [https://github.com/VarnikChoudhary/Portfolio.git](https://github.com/VarnikChoudhary/Portfolio.git)
cd Portfolio

```


2. **Install dependencies:**
```bash
npm install

```


3. **Start the development server:**
```bash
npm run dev

```


4. **View in Browser:**
Open `http://localhost:5173` to view the app.

## 🚀 Deployment

To build for production (Vercel/Netlify/GitHub Pages):

```bash
npm run build

```
